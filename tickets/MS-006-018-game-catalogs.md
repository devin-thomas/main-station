# MS-006–018 — Founding Game catalog tracks

**Depends on:** MS-004

One independently auditable track each covers 2XKO, Marvel Tokon, MvC2, UMVC3, UNI2, Avatar Legends, Melee, Guilty Gear XX Accent Core Plus R, Vampire Savior, SF6, MK1, Tekken 8, and Guilty Gear Strive.

Each track owns the exact Game Version label, roster, complete selection rules, required options, factual summary sources, and one art-rights record per image. No placeholder is represented as complete launch data.

**Acceptance:** the track validator passes; roster and schema are verified against primary or specialist sources; summaries distinguish licensed reuse from attributed paraphrase; images record source, creator/publisher, usage basis, review state, and takedown path.
