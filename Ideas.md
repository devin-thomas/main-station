# MainStation Ideas

These ideas are deliberately outside the current discovery commitment unless promoted later.

- Recommend an entire fighting game or subgenre from a Taste Profile.
- Import match or character-usage history from game APIs where reliable and permitted.
- Link tournament records or claimed competitive profiles without making them required for ordinary users.
- Find players with similar or complementary main patterns.
- Generate event-ready profile cards, commentator cards, or stream overlays.
- Track how a player's mains and taste change over time.
- Support reputation, expert panels, and game-specific review councils for authored character knowledge if a community editorial workflow is later adopted.
- Add a "Why I Play Them" section to each Character Landing Page. Registered players may comment only when their public profile contains eligible usage of that Character; moderation must be designed before promotion into scope.
- Explore free-text explanation signals only after the structured profile model has enough data and a privacy, moderation, and evaluation approach exists.
- Publish anonymized, provenance-labeled aggregate trends similar to Tokon Teams.
- Add team-composition recommendations after single-character discovery is trustworthy.
- Offer a preference quiz for players with no established fighting-game mains.
- Provide creator/editorial guides attached to recommendation explanations.
- Support private profiles and small friend-group comparison spaces.
- Add further fighting games through named, community-backed release waves after the founding catalog is trustworthy.
- Consider restrained advertising only if usage creates material operating costs that free tiers and student resources cannot sustain.
